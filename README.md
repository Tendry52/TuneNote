# TuneNote

Accordeur chromatique en temps réel basé sur la **Transformée de Fourier Discrète**.

Nom: ANDRIANIHASINAVALONA Tendry Irina n°23

## Installation

```bash
pip install -r requirements.txt
```

## Utilisation

```bash
python main.py
```

Cliquer sur **Démarrer** pour activer le micro, puis sur **Arrêter** pour l'interrompre.
